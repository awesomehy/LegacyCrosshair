# Legacy Crosshair / 旧版 CS 准星

Windows 原生准星工具，面向 2026 年 9 月更新前的经典 CS 准星体验。首版提供经典静态和按 WASD 模拟的经典动态模式、实时效果预览，以及游戏分辨率到显示器的独立横纵轴映射。

**当前版本：1.0.0。** 首个正式发布版，提供简约明亮 / 深色双主题、统一的圆角控件与实时预览，并包含后台 CPU、内存占用优化及静态模式的动态功能停用。这是旧版体验的独立重建，尚未用更新前后的游戏实机截图和运动数据完成逐像素、逐帧对照。动态模式以按键模拟移动状态，不代表游戏真实散布。

0.1.1 修复了非整数拉伸下描边左右 / 上下不等宽的问题：先映射准星线条，再按每个轴的统一整数像素厚度添加描边。比如 1440×1080 拉伸到 1920×1080 时，不再出现左侧 1 像素、右侧 2 像素的黑边。预览与覆盖层同时生效，已有配置可继续使用。

## 启动

支持 Windows 10 1703 及以上 / Windows 11，x64，需安装 .NET Framework 4.8 或以上。

从 [GitHub Releases](https://github.com/awesomehy/LegacyCrosshair/releases/latest) 下载 `LegacyCrosshair-v1.0.0-win-x64.zip`，解压后保留 `LegacyCrosshair.exe` 与 `LegacyCrosshair.exe.config` 在同一文件夹，双击 EXE。无需管理员权限。单独下载 EXE 时，也请下载对应的 `.exe.config` 文件以启用正确的高 DPI 适配。源码目录也可双击 `run.cmd`，首次运行会调用 Windows 自带的 C# 编译器构建。

程序启动时覆盖层保持关闭；右侧预览立即可用。点击“开启覆盖层”显示桌面准星。关闭设置窗口会退出程序；最小化会隐藏至托盘，双击托盘图标恢复。

| 快捷键 | 功能 |
| --- | --- |
| Ctrl + Alt + X | 开启 / 关闭准星覆盖层 |
| Ctrl + Alt + S | 打开设置窗口 |

快捷键若被其他程序占用，可使用按钮和托盘菜单。

## 第一次配置

1. 在“快速预设”中选择经典静态或经典动态。
2. 在“显示”页选择目标显示器，并填写 **游戏设置中的渲染分辨率**，不要把 Windows 的缩放百分比当作游戏分辨率。
3. 如果游戏使用 4:3 拉伸，选择“铺满屏幕 / 4:3 拉伸”；如果使用黑边，选择“保持比例 / 黑边”。
4. 调整长度、粗细、间距、描边和颜色；“更多外观设置”中可调整描边宽度、中心点、T 形和透明度。预览和覆盖层共用同一套像素渲染结果。
5. 使用动态模式时，保留“全局 WASD 监听”。按键无需预览窗口获得焦点；右侧按键指示块会显示输入状态。静态模式自动停用监听和动态设置，切回动态后恢复原有参数。
6. 点击“开启覆盖层”，再最小化设置窗口进入游戏。

例如游戏为 **1280×960**、Windows 输出为 **1920×1080**：拉伸模式横轴为 1.5 倍，纵轴为 1.125 倍；黑边模式两轴均为 1.125 倍，画面左右各留 240 像素。映射以当前显示器的物理像素为准，显示器分辨率变化后会重新计算。

“对齐 CS2 窗口”会跟随可见的 `cs2.exe` 窗口客户区；找不到窗口或游戏最小化时隐藏准星并等待。“仅在 CS2 前台显示”可避免在其他应用中显示覆盖层。默认使用所选显示器中心；已保存的显示器离线时回退到主显示器并提示。

普通桌面覆盖层适用于窗口化 / 无边框窗口。独占全屏可能遮住覆盖层；遇到这种情况使用无边框窗口。游戏原生准星仍由游戏控制，使用本工具时可自行在游戏设置中关闭，以免重叠。

## 界面与主题

右上角可随时切换“明亮 / 深色”，选择会自动保存。主题仅改变界面配色，不改变准星颜色、参数或像素结果；已有配置可直接继续使用。

界面采用统一字体、圆角卡片、分段导航、动画滑动开关和自绘下拉菜单。数字可直接输入，按 Enter 或离开输入框后生效，方向键可微调；无效输入会恢复原值。下拉菜单支持鼠标滚轮、方向键、Enter 确认和 Esc 关闭。较少使用的参数收纳在“更多外观设置 / 分段详细设置”内，小窗口下可滚动查看。

Windows 11 的原生标题栏随主题切换；较早系统使用系统标题栏。

## 静态与动态行为

- 经典静态对应 style 4 的基本形态。支持小数长度 / 粗细、负间距、描边、透明度、中心点和 T 形。
- 经典动态以 style 2 的内外分段形态为参考。WASD 经加速、反向刹停、松键恢复模型得到扩散量；同时按 W+A+D 仍保留前进，斜向输入不会突破最大扩散。
- “移动扩散”使用旧准星长度单位，默认按 `游戏高度 / 480` 换算；“阈值 · px”直接使用游戏像素。时间参数为指数响应的时间常数，**不是达到终点的固定时长**。
- 内外段长度比例和透明度可调。关闭“动态内外分段”即可使用整体扩散。
- 当前输入固定为 WASD，不读取游戏内自定义绑定。走路、蹲伏、跳跃、射击、武器类型、游戏失焦后的实际移动结果均不参与模型。
- 长度和粗细参考旧版整数像素量化；间距单独处理，保留负值。真实旧版在各分辨率下的边界取整、描边和动态细节仍需实机校准。

Raw Input 在后台消息窗口接收键盘状态，按键变化直接唤醒动态动画，并定期检查当前按键以修复丢失的松键事件；注册失败时会提示并使用按键状态轮询。仅保留 WASD 当前状态，不保存键盘文字或历史。程序不读取游戏内存，不向游戏注入代码或发送输入。

## 预览

默认以 **1:1 物理像素** 展示屏幕中心局部，并在空间足够时附整数倍像素放大镜；“全屏构图”按比例缩小完整输出画面。背景可在示意训练场、深色、浅色和棋盘之间切换。训练场是程序绘制的示意画面，不是游戏截图。

“按住模拟移动”和“自动演示”仅驱动预览。即使正在演示，桌面覆盖层仍使用真实 WASD 状态。静态模式下演示不会产生扩散。

## 性能与游戏时使用

优化自动生效，无需额外开启。**静态模式使用独立的运行路径**：不注册 WASD Raw Input、不读取按键、不计算运动模型、不运行演示或创建动态预览帧；动态设置和演示按钮暂时禁用。切回经典动态后自动恢复监听与保存的动态参数。Ctrl+Alt 全局快捷键仍可使用。

进入游戏前最小化设置窗口至托盘，可停止预览和演示绘制，并释放界面绘图缓冲；准星覆盖层与全局快捷键继续工作。

- 静态画面没有变化时，不重复绘制预览或上传覆盖层。没有保存、窗口跟随等待处理任务时，刷新定时器完全停止。
- 动态动画变化期间请求 16 ms 更新；状态收敛后降低频率，按键变化通过 Raw Input 立即唤醒。预览仅在内容改变时绘制，最高 30 次 / 秒；覆盖层独立更新，不受预览上限限制。程序不提高系统定时器精度。
- 缓存少量重复出现的准星位图，每组最多 12 项、通常不超过 256 KiB；超大单帧单独保留。覆盖层复用原生 DIB 画布，减少反复创建图像、设备上下文和垃圾回收。
- 关闭覆盖层且界面隐藏时释放准星缓存并暂停 WASD 监听；静态模式下即使设置界面可见也不监听 WASD。恢复动态准星使用时自动恢复监听。
- 未启用 CS2 窗口跟随时不扫描游戏进程。启用后缓存窗口句柄，游戏未启动时最多每 2 秒重新查找一次。前台限制使用系统窗口切换事件；事件注册失败时采用低频检查。

这些优化减少工具自身的工作量。CS2 内 FPS、1% low 和帧时间尚未实测，不能把工具 CPU 的降幅直接换算成游戏帧率提升。

同机对照（2026-10-26，16 个逻辑处理器，2560×1440 输出，默认准星 / 1280×960 拉伸）：每种场景预热 1.5 秒、采样约 10 秒。动态后台场景通过测试输入交替前进、左移、松键；未启用游戏窗口跟随或前台限制，没有运行 CS2。

| 场景 | 0.2.0 CPU 时间 | 0.2.1 CPU 时间 | 私有内存 0.2.0 → 0.2.1 |
| --- | ---: | ---: | ---: |
| 设置可见，静态空闲 | 1750 ms | 0 ms | 39.8 → 31.7 MiB |
| 设置可见，动态演示 | 1500 ms | 313 ms | 37.7 → 34.8 MiB |
| 设置隐藏，静态覆盖层 | 250 ms | 0 ms | 37.0 → 35.1 MiB |
| 设置隐藏，动态覆盖层 | 281 ms | 0 ms | 37.6 → 36.6 MiB |

CPU 时间为该进程在整个采样段累计消耗的处理器时间，0 ms 表示低于本次计时分辨率；不是游戏帧时间。数据包含测试驱动的少量开销，也会受系统状态影响。原始记录为 `artifacts/performance-baseline-10s.json` 与 `artifacts/performance-optimized-10s.json`，可用下方脚本在本机复测。

## 配置

设置修改后自动保存至 `%LOCALAPPDATA%\LegacyCrosshair\settings.json`，上一次保存保留为 `settings.json.bak`。配置读取失败会使用默认值并提示，异常诊断写入同目录的 `error.log`。

“显示”页支持导入 / 导出本工具的 JSON 配置。`presets` 文件夹提供静态和动态示例。这不是 CS2 的 `CSGO-...` 准星分享码；当前版本尚未提供分享码编解码。

卸载时退出程序并删除解压文件夹即可；若需清理个人设置，再删除上述 `LegacyCrosshair` 配置文件夹。

## 构建与验证

在源码目录运行 PowerShell：

```powershell
.\build.ps1                    # 编译 Windows 应用
.\build.ps1 -Test -SmokeTest    # 核心测试 + 短暂启动原生窗口进行联动检查
.\tests\MeasurePerformance.ps1 -Label current  # 四种场景，每种采样 10 秒
.\package.ps1                 # 构建并生成 dist 下的便携 ZIP
```

无需 NuGet、Node.js 或 dotnet SDK。使用 Windows .NET Framework 自带的 `csc.exe`，源码兼容 C# 5。发布包须同时包含 EXE 与 `.exe.config`，后者启用每显示器 V2 DPI 适配。

当前 44 项核心检查与 59 项界面联动检查全部通过。覆盖像素几何、动态响应、4:3 拉伸与黑边、负坐标显示器映射、透明度、配置读写，以及实际 Win32 覆盖层的显示、位置、鼠标穿透、置顶和不抢焦点属性。界面检查还验证主题切换不改变准星像素、下拉菜单键盘操作、数字输入、折叠设置、滚动及紧凑窗口布局；性能回归检查验证静态路径完全跳过动态工作、模式切换恢复参数、空闲休眠、按键事件唤醒、松键与变向响应、位图缓存上限、DIB 资源复用及像素透明度。测试会在 `artifacts` 生成程序自己的离屏界面渲染图和性能 JSON；UI / 性能测试使用独立配置，不覆盖个人设置。

本机只有一块可用测试显示器。多显示器负坐标由几何测试验证，高 DPI 已验证进程采用 PerMonitorV2；跨不同 DPI 的物理显示器、独占全屏和 CS2 内实际按键 / 旧版手感尚未实机验证。

源码结构：`Core.cs` 为配置、运动模型和纯渲染；`Native.cs` 为 Raw Input 与 Win32 覆盖层；`MainForm.cs` 为设置和状态管理；`MainForm.Ui.cs` 为界面布局；`Theme.cs` 为双主题与自绘控件；`Preview.cs` 为预览。
